# ramen-bookmarker-legal

「ラーメンブックマーカー」（ラーメン店のブックマーク・来店記録アプリ）の公開法的文書（プライバシーポリシー等）を配信するための公開リポジトリです。

アプリ本体のソースコードは非公開リポジトリで管理しています。このリポジトリは、App Store Connect等に登録する公開URLを発行するためだけに存在します。

- プライバシーポリシー: https://creatibooks.github.io/ramen-bookmarker-legal/privacy-policy.html
- Privacy Policy (English): https://creatibooks.github.io/ramen-bookmarker-legal/en/privacy-policy.html
